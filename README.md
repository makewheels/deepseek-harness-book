# 从零读懂 DeepSeek Harness

一本写给**不读代码的人**的 DeepSeek Harness（dsh）学习书。

- 风格参照李博杰《深入理解 AI Agent》（案例驱动、编号实验、思考题、章末小结），但全部用大白话讲。
- 源材料：[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) 源码与官方文档 + 本机实机运行验证。
- 构建：Markdown + Material for MkDocs。

## 本地阅读

```powershell
cd C:\workspace\github\deepseek-harness-book
.venv\Scripts\mkdocs serve
```

浏览器打开 http://127.0.0.1:8000 。
