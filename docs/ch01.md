# 第1章 什么是 Agent Harness

!!! quote "本章导读"
    读完本章你会明白：为什么光有大模型干不了活；harness 是给模型装的什么东西；dsh 在这波开源浪潮里特别在哪。

## 1.1 大脑只会一件事

先做个思想实验。

你对着一个纯聊天的大模型说：

> "把我桌面上散落的文件按类型归归类，图片放一堆，文档放一堆。"

它会怎么回答？大概率是这样：

> "好的，你可以这样做：第一步，在桌面新建两个文件夹；第二步，右键点击文件选择移动到……"

它给你写了一份**整理桌面指南**。很贴心，但你的桌面还是一个字没动。

这不是模型笨。你再聪明的大脑，被关在一个黑屋子里、没有眼睛没有手，也只能靠嘴输出建议。大模型的处境就是这个黑屋子：

- **它看不见**——你的桌面、你的文件、你的日历，它一概不知道
- **它动不了**——建文件夹、移动文件、发邮件，它一个动作都做不了
- **它记不住**——关掉对话窗口，刚才聊的一切全部清零

它唯一会做的事，是**读一段文字，写一段文字**。仅此而已。

那为什么现在的 AI 助手又能帮你干活了？因为有人给大脑造了一副身体。

## 1.2 身体，以及它的名字：Harness

这副身体有个正式名字，叫 **agent harness**——直译过来是"挽具"，就是套在马身上、让马能拉车的那套装备。模型是那匹马，力气很大，但光有马没法运货；挽具把马套上车，才变成了运力。

DeepSeek 内部开发者给过一个更生动的类比：

> 可以把 dsh 想象成一个乐高汽车玩具。官方提供的 Coding Agent，只是他们自己拼出来的一套预置。你完全可以把里面的零件换成自己喜欢的：换引擎、换轮胎、换挡风玻璃。甚至最后拼出来的东西，也不一定还是一辆汽车。

身体上有哪些器官？拆开看，一副完整的 harness 至少有五样东西：

| 器官 | 干什么 | 生活类比 |
|---|---|---|
| 👁️ 眼睛 | 读文件、看屏幕、查日历 | 大脑的感知输入 |
| 🤚 手 | 执行命令、改文件、发消息 | 大脑的动作输出 |
| 🧠 外挂记忆 | 把这轮对话发生的事逐笔记账 | 会议纪要员 |
| 📏 规矩 | 哪些事能直接干，哪些要先问你 | 公司审批流 |
| 🔁 循环 | 干一步→看结果→决定下一步，直到干完 | 项目经理盯进度 |

于是黑屋子里的大脑变成了这样：它说"我想看看桌面上有什么文件"，**身体替它看**，把结果念给它听；它说"把这三张图片移走"，**身体替它移**，再汇报结果。大脑负责想，身体负责干，一来一回，活就干完了。

**Agent = 大脑 + 身体。** 现在你听到的所有 "AI agent" 产品，本质都是这个公式。区别只在：用的哪个大脑，身体是怎么造的。

## 1.3 一次"整理桌面"的完整往返

把上面的器官串起来，看一次真实的往返。你说"整理我的桌面"之后，幕后发生的事大概是：

1. **身体**把你的话连同"你此刻能用哪些工具"的清单，一起递进黑屋子
2. **大脑**想了想，写下：「我要先用"列目录"这个工具，看看桌面上有什么」
3. **身体**看到大脑要用工具，替它执行"列目录"，拿到 23 个文件的清单
4. **身体**把清单念给大脑听，同时把这一切记进会议纪要
5. **大脑**又写：「我要用"移动文件"，把其中 8 张图片移进『图片』文件夹」
6. **身体**执行，汇报成功
7. 来回好几轮，直到大脑写下：「干完了，这是整理结果」
8. **身体**把这句话显示给你

注意第 3 步和第 5 步：大脑从头到尾没有碰过你的硬盘，它只是**申请用工具**，真正动手的永远是身体。这条分界线是全书最重要的概念之一，第 6 章讲工具流水线时会反复用到。

还要记住一件事：每一轮"大脑说话→身体干活→汇报结果"，都会被记进那本会议纪要（会话日志）。以后你会看到，dsh 有一条铁律——

> **模型看到的每一句话，都必须能在日志里找到出处。**

为什么这么严格？第 5 章揭晓。

## 1.4 那 dsh 到底是什么

**DeepSeek Harness（命令名 `dsh`）就是 DeepSeek 官方造的那副身体，而且把图纸全部公开了。**

三个关键词：

- **官方出品**——不是第三方攒的，是 DeepSeek 自己用来做产品的底盘，MIT 许可证开源
- **一切皆插件**——眼睛、手、记忆、规矩，每一个器官都是一个可拆可换的零件。想换掉官方装的"手"？拔下来，插上你自己的
- **两种形态**——一种带网页界面（你在浏览器里跟它聊），一种没有界面（一条命令扔进去，它自己干完活再告诉你结果）

DeepSeek 自己用它拼了一辆"官方预置汽车"——一个能干编码活的 agent。但 dsh 的价值不在那辆车，而在**它把造车的全套零件和图纸都给了你**。

## 1.5 同类这么多，为什么学 dsh

你可能听过 Claude Code、Codex、OpenHands 这些名字。它们和 dsh 是什么关系？一张表说清：

| 名字 | 它是什么 | 身体公开吗 |
|---|---|---|
| Claude Code | Anthropic 的成品 agent 产品 | ❌ 闭源，你只能用，不能拆 |
| Codex | OpenAI 的成品 agent 产品 | ❌ 同上 |
| OpenHands | 开源的 agent 平台 | ✅ 开源，但偏向"搭好舞台让 agent 演戏" |
| DeerFlow | 字节开源的深度研究框架 | ✅ 开源，专注"调研报告"这一种活 |
| **dsh** | **开源的 agent 零件库 + 组装手册** | ✅ **一切皆插件，每个器官都能单拆** |

一句话：别的产品给你一辆车，dsh 给你的是**造车车间**。想理解"一辆 agent 汽车到底由哪些零件构成、为什么这么设计"，dsh 是目前最好的解剖标本。

这也是本书的讲法：第二部分逐个器官解剖，第三部分看它怎么保护自己的手不闯祸，第四部分你自己上手换零件。

## 1.6 先打一针预防针

dsh 现在是**开发者预览**阶段——官方原话是"未来将出现破坏兼容性的变更"。翻译成大白话：零件规格还会变，今天能装的接口明天可能就换了形状。

这本书以 **2026 年 8 月中旬**的仓库为准。如果你实际操作时发现和书上对不上，多半不是书错了，是它又迭代了——**以你本机跑出来的为准**，这是贯穿全书的原则。

## 🧪 本章实验

**实验 1-1 ★｜看看这匹马长什么样**
打开 dsh 的 GitHub 仓库页面（github.com/deepseek-ai/deepseek-harness），不用读代码，只看三样东西：star 数（多少人关注）、README 里的 "Everything is a Plugin" 口号、还有目录里 `packages/` 文件夹的数量。建立第一印象：这不是玩具，是一个几十万人围观的严肃项目。

**实验 1-2 ★★｜检查你的电脑准备好了没**
dsh 需要 Node.js 才能跑。打开终端输入 `node -v`，如果显示 v22 以上的版本号就万事俱备；如果提示"不是内部或外部命令"，先去 nodejs.org 装一个。第 2 章要用。

## 🤔 思考题

1. "大脑只会读文字、写文字"——你觉得这条限制是暂时的（以后模型会直接长出手），还是永恒的（手永远要靠身体提供）？
2. 为什么"真正动手的永远是身体，大脑只负责申请"这条分界线，对安全来说是好事？
3. 如果让你给自己的工作配一个 agent，你最想让它先长出哪只"手"？

## 📝 小结

- 大模型只是大脑：看不见、动不了、记不住，只会读写文字
- harness 是给大脑装的身体：眼睛、手、外挂记忆、规矩、循环，五样器官
- Agent = 大脑 + 身体；所有 agent 产品都是这个公式的不同组合
- dsh 是 DeepSeek 官方开源的身体，特点是"一切皆插件"，每个器官可拆可换
- 学 dsh 的价值：它是目前最好的 agent 解剖标本
